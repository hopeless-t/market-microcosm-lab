# E011 — Market pressure knee

E010 showed that all initial mechanism candidates survived the neutral 60-month baseline. E011 therefore increases environmental pressure until the viability boundary becomes visible.

## Pressure axis

Each integer pressure level simultaneously:

- lowers subscription price/revenue;
- raises platform operating cost;
- raises baseline user churn.

This is intentionally a composite stress axis. Later experiments will separate the dimensions after the first knees are located.

## Outputs

For every mechanism and pressure level:

- survival rate;
- Wilson lower confidence bound;
- ecosystem health;
- user utility;
- diversity;
- active developer count;
- platform cash;
- entry/exit counts.

The first pressure level with observed survival below 90% is recorded as the preliminary knee.

## Failure biopsy

At each mechanism's knee, E011 searches a separate seed bank for a concrete collapse trajectory and stores month-by-month state metrics.

Failure traces are evidence for the next theory update; they are not discarded as outliers.

## Interpretation discipline

A mechanism with a later knee is more robust **inside this declared synthetic world and stress definition**. It is not automatically better for a real market.
