# E010 — Ecological market dynamics

E010 is the first market microcosm with a complete economic circulation.

## Cycle

Users -> subscription revenue -> platform -> creator pool -> publishers/developers -> content availability -> user utility -> churn/acquisition -> next-period revenue.

Developers and publishers carry cash buffers and monthly costs. They can exit. A dormant entrant can enter when the creator economy is sufficiently attractive. Content disappears when its developer or required publisher is no longer viable.

## Mechanisms compared

- usage-only;
- light survival floor;
- balanced floor + ecosystem fund;
- diversity-heavy fund;
- creator-heavy split;
- platform-heavy split.

The ecosystem fund is allocated toward the currently least represented content segment. This is a stylized mechanism, not a claim that real platforms should implement the exact rule.

## Protected quantities

Promotion is lexicographic:

1. accounting invariants;
2. ecosystem survival;
3. user utility;
4. developer viability;
5. ecosystem health improvement.

A challenger cannot buy a higher health score by violating protected quantities.

## Independent evidence

E010 uses separate seed banks for:

- candidate discovery;
- inner promotion;
- outer meta evaluation;
- neutral baseline reporting.

## What E010 is for

E010 asks whether allocation rules that look locally efficient can create long-run ecological collapse, and whether floor/fund mechanisms can enlarge the practical survival region.

It is still synthetic. Its purpose is structural exploration and testing of the closed improvement machinery, not empirical estimation of any named service.
