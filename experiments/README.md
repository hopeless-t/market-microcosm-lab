# Experiments

Every experiment directory should contain enough information to reproduce and falsify the result.

Minimum record:

1. question and hypothesis;
2. world/model version;
3. Root-of-Trust generation;
4. discovery, promotion, and meta-holdout split;
5. policy/mechanism candidates;
6. protected constraints;
7. metrics and promotion rule;
8. run manifests / seeds;
9. results including failures;
10. interpretation, limitations, and falsification conditions.

E000 is the executable reference experiment. Later experiments may become larger, but they do not replace E000 as the exact-check calibration target.
