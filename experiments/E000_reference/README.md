# E000 — Reference micro-world

Purpose: establish a tiny, auditable world before adding realism.

## Initial actors

Start with one platform, two developer types, one publisher type if needed, and a small number of user preference types.

## First questions

1. Under usage-proportional payout, when does one developer class disappear?
2. Does adding a survival floor enlarge the viability region?
3. Does an ecosystem fund preserve diversity without making the platform insolvent?
4. Where are the pressure knees for take rate, floor size, shock frequency, and demand concentration?
5. Can an approximate controller reproduce exact finite-state answers?

## Required outputs

- deterministic trajectory manifest;
- conservation/invariant report;
- time-to-first-constraint-violation;
- minimum viability margin;
- actor exit/entry counts;
- user utility and service quality;
- concentration/diversity metrics;
- challenger vs incumbent evidence.

E000 is not meant to be realistic. It is the calibration target for the laboratory machinery itself.
