# ODD addendum — E091 replacement KPI backfill is not a construct bridge

## Purpose

E079–E080 treat the withdrawal of old overseas-SaaS KPIs as an observation-kernel break.

By FY2025 Q1, Allied Architects introduces a new KPI: **revenue per employee**.

The presentation defines it as domestic-business revenue divided by average domestic full-time employees and states that 2024 quarterly values are retrospectively calculated under the same definition.

E091 asks whether that backfill reconnects the new KPI to the withdrawn ARR/churn series.

## Two kinds of continuity

Inside the new metric generation, the retrospective 2024 values and 2025 values share one definition. Comparison is authorized.

Across constructs:

- old ARR: recurring-revenue run rate, overseas-SaaS scope;
- new revenue per employee: labor-productivity revenue intensity, domestic-business scope.

Construct, formula, and scope differ.

Therefore:

`REJECT_CONSTRUCT_BRIDGE`

## Consequence

Retrospective backfill repairs **within-metric temporal continuity**.

It does not create **cross-metric semantic continuity**.

Promotion:

`replacement-kpi-backfill-does-not-bridge-different-constructs-v1`
