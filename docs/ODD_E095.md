# ODD addendum — E095 residual capability value after SaaS exit

## Purpose

E093 establishes that Jooto's standalone growth-business viability was not sufficient to justify continued investment.

E095 attacks the stronger label:

`business exit => everything built by the business is worthless`

## Public evidence

PR TIMES states that Jooto's customer base, technology and know-how retain important value.

It also states:

- the Toyota custom work-management tool `標準の箱` is outside the Jooto general-service shutdown and continues;
- employees working on Jooto are, in principle, to be gradually redeployed into other internal businesses where their knowledge and experience can be used.

## State separation

The reference therefore permits both statements to be true:

`standalone growth viability = not established`

`residual capability value = nonzero / retained`

No monetary residual value is inferred.

## Consequence

A strategic exit can be a portfolio-reallocation action rather than a total destruction of accumulated capability.
