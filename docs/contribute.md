# Contribute

The project welcomes contributions that make the ecosystem harder to fool or easier to falsify.

## High-value contributions

- new market mechanisms with clear failure hypotheses;
- adversarial or rare-event stress worlds;
- exact small-world checkers;
- improved failure biopsy;
- causal estimators;
- alternative evaluators;
- meta-evaluation methods;
- accounting or transition audits;
- reproducibility improvements.

## Start with an issue

The repository provides structured forms for:

- **Research hypothesis** — propose a falsifiable question;
- **Failure biopsy** — preserve and explain a collapse trajectory.

Pull requests also contain an evidence checklist so discovery and certification do not silently mix.

[Open the repository](https://github.com/hopeless-t/market-microcosm-lab) · [Read CONTRIBUTING](https://github.com/hopeless-t/market-microcosm-lab/blob/main/CONTRIBUTING.md)

## Before claiming an improvement

Ask:

1. What would falsify this?
2. Which evidence was used for discovery?
3. Which evidence was untouched until promotion?
4. Which hard constraint could not be traded away?
5. Could another implementation replay the result?
6. What failure case was retained rather than discarded?
