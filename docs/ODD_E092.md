# ODD addendum — E092 post-exit horizon guard

## Purpose

E090 observes a real post-exit sign reversal: FY2025 Q1 operating profit is +16m JPY after FY2024 Q1 was -229m.

E092 attacks the overclaim:

`one positive quarter => durable profitability restored`

## Longer horizon

FY2025 H1 cumulative results report:

- revenue: 1,499m JPY;
- operating loss: -49m JPY.

FY2024 H1 had:

- revenue: 1,731m JPY;
- operating loss: -285m JPY.

So operating performance improves by **236m JPY** year-on-year, but the half-year remains loss-making.

## Authority

E090's directional claim survives:

`operating economics improved`

The stronger durable-profitability claim does not:

`IMPROVING_BUT_NOT_DURABLY_PROFITABLE`

## Consequence

Performance authority carries an observation horizon. A short-window sign flip cannot silently define the long-window state.

Promotion:

`one-quarter-profit-sign-flip-does-not-certify-durable-profitability-v1`
