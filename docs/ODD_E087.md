# ODD addendum — E087 public governance checkpoint timeline

## Purpose

E086 prevents a KPI-withdrawal warning from becoming a deterministic exit command.

E087 asks whether the real Allied timeline contains an intermediate governance checkpoint.

## Public sequence

**2024-02-14 — REPORTING_REGIME_BREAK**

The overseas-SaaS recurring KPI set is withdrawn after deterioration and many Q4 cancellations.

**2024-08-14 — EXPLICIT_EXIT_CRITERIA_BOUND**

The FY2024 H1 presentation states that the overseas subsidiary's restructuring was nearly complete and that management had set **stricter withdrawal criteria** and enforced budget-vs-actual management against those criteria.

**2024-10-31 — EXIT_CONFIRMED**

The board resolves dissolution and winding-up after concluding that early profitability improvement is extremely difficult and business continuation is difficult.

The first and last public events are 260 days apart.

## Consequence

The empirical path is not:

`warning -> automatic exit`

It is better represented as:

`reporting break -> explicit exit criteria checkpoint -> realized exit decision`

This mirrors the lab's broader principle that only indispensable governance checkpoints should carry authority transitions.

Promotion:

`deterioration-governance-path-uses-explicit-exit-criteria-checkpoint-v1`

## Limitation

Public materials establish that stricter exit criteria existed, but do not disclose their full private threshold values. E087 neither reconstructs those thresholds nor claims the checkpoint caused the later exit.
