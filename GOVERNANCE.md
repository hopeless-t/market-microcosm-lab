# Governance

Market Microcosm Lab uses lightweight research governance.

## Layers

**Maintainers** may accept code and documentation, but accepted code is not automatically accepted evidence.

**Root of Trust** defines same-generation invariants: accounting conservation, oracle isolation, held-out isolation, replay identity, and independent promotion.

**Verifier** decides whether a challenger satisfies declared promotion requirements.

**Meta-Governor** may improve observation, search, stress curricula, and evaluation machinery, but it may not silently weaken the constitution that judges the same generation.

## Constitutional changes

A change to `spec/ROOT_OF_TRUST.md` or protected viability semantics should explain why the old rule is inadequate, define the new failure mode addressed, create a new evaluation generation conceptually, and re-evaluate incumbent evidence.

Historical results remain historical evidence; they are not silently rewritten.

## Real-world claims

Synthetic experiments can motivate hypotheses about real markets. They do not become empirical claims without separate calibration, identification, and external validation.
